# StuDuckAPP

**StuDuck** — это десктопное приложение для студентов, которое помогает организовать учебный процесс: отслеживать оценки, расписание, новости и общаться в учебных группах.

Проект выполнен в рамках курсовой работы.

---

## Функциональные возможности

- **Новости и объявления** – актуальная информация от учебного заведения
- **Успеваемость** – отслеживание оценок, результатов тестов и экзаменов
- **Расписание** – просмотр пар по дням с указанием времени и аудитории
- **Напоминания** – уведомления о дедлайнах и предстоящих экзаменах
- **Учебные группы** – совместное обучение, обмен заметками и обсуждения
- **Полезные ресурсы** – учебные материалы, советы по подготовке, статьи

---

## Технологии

- **C# / Windows Forms** – интерфейс и логика приложения
- **SQL Server / LocalDB** – база данных (пользователи, оценки, расписание)
- **SQL Server Management Studio (SSMS)** – работа с БД и создание скриптов
- **Git / GitHub** – контроль версий
